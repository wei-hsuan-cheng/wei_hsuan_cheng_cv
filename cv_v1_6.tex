    \section{Research Experience}
        
        \begin{twocolentry}{
        \textit{Taipei, Taiwan}    
            
        \textit{Dec 2023 – May 2025}}
            \textbf{\href{https://dnc.ntu.edu.tw/en}{Delta-NTU Joint Research \& Development Centre}}
            
            \textit{Project leader in the collaboration research project of NTU and the CTO Office in Delta Electronics, Inc.}
        \end{twocolentry}

        \vspace{0.10 cm}
        \begin{onecolentry}
        \textbf{Supervisory Teleoperation of Manipulator for Surveillance}
            \begin{highlights}
                \item Develop a reliable supervisory robotic system for performing dexterous manipulation tasks in industrial surveillance scenario (\textit{e.g.} buttons, switches, and valves operations). The system utilises a local–remote teleoperation setup with wireless communication, separating the local site—which comprises the control console, user interface, and input device—from the remote site, where the robot performs tasks with sensors and algorithms deployed.
                \item \textbf{Unified 6-DoF Vision Alignment:} Employ a state-of-the-art deep learning method for 6D object pose estimation with a position-based visual servo (PBVS) control scheme. This combination serves as a unified 6-DoF vision alignment method, which is essential for performing precise manipulation tasks for versatile objects in industrial settings.
                \item \textbf{Vision Alignment Corrected by Force:} Apply force control to further correct the vision alignment errors. The integration of two complementary sensory modalities (vision-and-force) provides enhanced accuracy for robotic dexterous manipulation.
            \end{highlights}

The key results of the project were successfully demonstrated to the CEO at the \textbf{2024 Delta
Electronics Annual Innovation Showcase}.

    \section{Selected Projects}

        \begin{twocolentry}{
            \hrefWithoutArrow{https://github.com/wei-hsuan-cheng/kf_cpp}{{\footnotesize\faGithub}\hspace*{0.13cm}kf\_cpp}\textit{, May 2023}
            }

            \textbf{Attitude and Angular Velocity Estimation of Surgical Robot Using Sensor Fusion with Optical Tracker, IMU, and Quaternion-based Extended Kalman Filter}
        \end{twocolentry}
        \vspace{0.10 cm}
        \begin{onecolentry}
            \begin{highlights}
                \item A multi-sensor fusion framework is used for estimating the attitude and angular velocity of surgical robot end-effector, for better robustness (against occlusions) and tracking precision in minimally invasive surgeries.
                \item An quaternion-based EKF algorithm is derived based on a constant angular velocity model.
                \item The EKF and UKF algorithm are implemented in ROS 2 C++.
            \end{highlights}
        \end{onecolentry}

        \vspace{0.2 cm}

        \begin{twocolentry}{
        \hrefWithoutArrow{https://github.com/wei-hsuan-cheng/kendo_robot}{{\footnotesize\faGithub}\hspace*{0.13cm}kendo\_robot}\textit{, Dec 2023}
        }
            \textbf{Kendo Robot: Combining Robotics Technologies with Martial Art}
        \end{twocolentry}
        \vspace{0.10 cm}
        \begin{onecolentry}
            \begin{highlights}
                \item A supervisory teleoperation kendo robot system. The robotic arm holding kendo sword tracks the opponent’s pose and wait for the operator’s command to attack on different body positions.
                \item Detect and track the 3D human body by DL-based real-time human pose estimation algorithm and RGB-D alignment. An interactive GUI is built using JavaScript for real-time visualisation and robotic motion planning.
                \item Robotic arm IK solver and sword motion planner are designed based on a new mathematical framework, conformal geometric algebra (CGA).
                \item Developed using ROS 1 Python, and a web-based interacture GUI uisng JavaScript. ROS-JavaScript communication through web socket.
            \end{highlights}
        \end{onecolentry}

        \vspace{0.2 cm}

        \begin{twocolentry}{
        \hrefWithoutArrow{https://github.com/wei-hsuan-cheng/cga_ik}{{\footnotesize\faGithub}\hspace*{0.13cm}cga\_ik}\textit{, Nov 2023}
        }
            \textbf{CGA IK: Closed-Form Inverse Kinematics Solver based on CGA}
        \end{twocolentry}
        \vspace{0.10 cm}
        \begin{onecolentry}
            \begin{highlights}
                \item Aim to promote a new mathematical framework \textbf{conformal geometric algebra (CGA)} for robotics applications. 
                \item Implemented closed-form IK solvers for a 6-DoF collaborative robot (cobot) and a 3-DoF spherical parallel manipulator (SPM) based on CGA.
                \item Simulated and visualised in a web-based interactive GUI using JavaScript. Implemented in  ROS 2 C++ and tested on a real robot.
            \end{highlights}
        \end{onecolentry}

        \vspace{0.2 cm}

        \begin{twocolentry}{
        \hrefWithoutArrow{https://github.com/wei-hsuan-cheng/stewart_platform_sim.git}{{\footnotesize\faGithub}\hspace*{0.13cm}stewart\_platform\_sim}\textit{, July 2025}
        }
            \textbf{stewart\_platform\_sim: Six-DoF Stewart-Gough Platform Simulation}
        \end{twocolentry}
        \vspace{0.10 cm}
        \begin{onecolentry}
            \begin{highlights}
                \item ROS 2 Python simulation of a six-DoF Stewart platform (or Stewart-Gough platform), which is a parallel manipulator comprising a fixed base platform, a moving end-effector platform, and six serial SPS sturctures.
                \item The inverse kinematics (IK) and differential kinematics (DK) problems are solved as to obtain the required leg lengths and leg velocities for driving the robot to achieve a desired motion in $SE(3)$.
            \end{highlights}
        \end{onecolentry}
